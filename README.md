# León (city): municipal law in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the law of Leon, Guanajuato, Mexico, which global-law reads at `mexico/guanajuato/leon/acts/`.

The municipal law of Municipio de León (Guanajuato, Mexico) as a git history: its reglamentos, one file per article, one paragraph per line, so `git log`, `git blame` and `git diff` work article by article.

It follows the shared design of [lexifina/global-law](https://github.com/lexifina/global-law), which places it at `mx-gua-leon/`. The law of the State of Guanajuato is in [lexifina/mexico-guanajuato-law](https://github.com/lexifina/mexico-guanajuato-law), and Mexico's federal law in [lexifina/mexico-law](https://github.com/lexifina/mexico-law).

The text is in Spanish, exactly as the source prints it.

## What this repository holds

97 reglamentos so far, each as its **current consolidated text only** (the oldest version available from the source), added in parts. León has no separate Bando de Policía y Buen Gobierno in the source's list: the first part holds its Reglamento de Justicia Cívica and Reglamento de Policía y Vialidad, then the Reglamento Interior del H. Ayuntamiento and the Reglamento Interior de la Administración Pública Municipal; the rest follow in the order the source lists them. Regulations the source marks as abrogated are left out.

## Source

Normatividad Municipal, Presidencia Municipal de León (normatividadmunicipal.leon.gob.mx), <https://normatividadmunicipal.leon.gob.mx/>. For each municipal regulation the site gives its record (publication in the Periódico Oficial del Gobierno del Estado de Guanajuato, type, and the list of its reforms with their Periódico Oficial dates) and its current text as a PDF (and a Word file). Earlier versions are not published there.

## Dates

- Each reglamento is one commit, dated at **noon, America/Mexico_City, on the date of its last reform** as the source records it. Its original text and earlier versions are not shown, because the source does not publish them.
- Versions dated after the retrieval day would go on the `futuro` branch, never merged into `main`.

## Files

`<reglamento>/art-005.md` is Artículo 5, `art-005-bis.md` Artículo 5 bis; `encabezado.md` holds the title and anything printed before Artículo 1. Chapter headings, transitorios and the reform notes the source prints stay in the file of the article they follow. One paragraph per line.

## How it is checked

- Every version is read back from git on its day (`tools/check_repo.py`) and must match `corpus.json`.
- The letters and digits of every version equal those of the source PDF read again with an independent reader (poppler's pdftotext), so no word is lost or added.
- Health checks: no merge commits, commit dates never go backwards, nothing dated in the future, and every commit's trailers parse.

## Limits

This is not an official publication. The binding text is the one published in the Periódico Oficial del Gobierno del Estado de Guanajuato. Only the reglamentos listed above are included, each as its current text only.
